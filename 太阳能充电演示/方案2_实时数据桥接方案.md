# 方案2 · BMS 实时数据桥接演示程序 —— 完整修改方案（待评审）

## 0. 目标
把 BMS 实时数据（光伏电流 I1 / 负载电流 I2 / 市电电流 I3 / SOC）从"BMS上位机"桥接给展会演示网页，
让 `太阳能充电演示/index.html` 支持"BMS 实时"数据源，替代手动滑块。

## 1. 已核实的前提（代码依据）
- **轮询**：`timer1.Interval = 1000`（Form1.Designer.cs:8925），`timer1_Tick` 在 `serialPort1.IsOpen`
  且当前标签页为 **"电池信息"或"校准"** 时调用 `Read_Batt_Data()`（Form1.cs:512-527）。
  → **有连续数据源，但演示时必须停在"电池信息"页**（见 §5 风险）。
- **字段**（Form1.cs 解析）：
  | 量 | 控件 | 偏移 | 换算 |
  |---|---|---|---|
  | 光伏电流 I1 | `iSolar` | 104~105 | 16 位原值 |
  | 负载电流 I2 | `Current` | 68~69 | 有符号 Int16 ×10 |
  | 市电电流 I3 | `iMainSupply` | 110~111 | 16 位原值 |
  | SOC | `SOC` | 79 | 0~100 |
  | 总压 | `vPack` | — | |
  | 光伏功率 | `pSolar` | 106~109 | 32 位 |
  | 负载功率 | `pLoad` | 112~115 | 32 位 |
- **电池电流** I4 由守恒式派生：**I4 = I1 + I3 − I2**。

## 2. 方案总览（架构）
```
┌─────────────────┐   内存共享最新快照    ┌──────────────────────────┐
│  BMS上位机 Form1 │ ───────────────────→ │  内置迷你 HTTP/SSE 服务   │
│  (每秒解析 BMS)  │                      │  127.0.0.1:8712           │
└─────────────────┘                      └────────────┬─────────────┘
                                                      │ HTTP / SSE
                                                      ▼
                                        ┌──────────────────────────┐
                                        │ 演示网页 index.html       │
                                        │ (BMS 实时数据源模式)      │
                                        └──────────────────────────┘
```
- 用 **`TcpListener` 手写极简 HTTP**（而非 `HttpListener`）——**免 URL ACL / 免管理员权限**。
- 服务顺带提供静态页 `GET /` → 直接返回 index.html，使网页与接口**同源，免 CORS**。

## 3. Part A —— 上位机（C#）改动

**A1. 新增 `BmsBridge.cs`（单文件，建议）**
- 持有"最新快照"字符串（`volatile string latestJson`），线程安全。
- `TcpListener` 监听 `127.0.0.1:8712`，后台线程 `Accept`，解析请求行：
  - `GET /api/bms` → 返回快照 JSON（`application/json`）
  - `GET /events`  → **SSE**（`text/event-stream`），每 ~150ms 推一次最新快照
  - `GET /` 或 `/index.html` → 返回演示页 HTML
  - 其它 → 404
- 响应加 `Access-Control-Allow-Origin: *`（以防网页从 `file://` 打开）。
- 全程 try/catch 吞异常并写日志；端口被占用时自动 +1 重试并把实际端口写日志。

**A2. 数据写入点**
在 Form1.cs 解析块末尾（约 **1925 行 `pLoad` 之后**）加一行：
```csharp
BmsBridge.Update(/*i1*/iSolar.Text, /*i2*/Current.Text, /*i3*/iMainSupply.Text,
                 /*soc*/SOC.Text, /*vpack*/vPack.Text, /*psolar*/pSolar.Text, /*pload*/pLoad.Text);
```
（Update 内部只做"拼 JSON + 赋值"，极轻量，可放心每 1s 调用一次。）

**A3. 启动/停止**
- `Form1_Load` → `BmsBridge.Start(8712);`
- `Form1_FormClosing` → `BmsBridge.Stop();`

**A4.（可选）UI 指示**
状态区加一行：`桥接服务：运行中  http://localhost:8712`。

## 4. Part B —— 演示网页 `index.html` 改动

**B1. 数据源三态（互斥）**：`手动` / `BMS 实时` / `自动演示`。新增"数据源"分段按钮。

**B2. 连接与取数**
- 优先 **SSE**：`new EventSource(CFG.api + '/events')`；`onmessage` → 更新数据。
- 回退 **轮询**：SSE 不可用/断开时，`fetch(CFG.api + '/api/bms')` 每 300ms。
- 顶部连接指示：`● BMS 已连接` / `○ 未连接（>2s 无数据）`。

**B3. 单位换算（关键）**
脚本顶部加配置：
```js
const CFG = {
  // 页面由服务提供时用相对地址（同源）；从 file:// 打开则连本机服务
  api: location.protocol.startsWith('http') ? '' : 'http://localhost:8712',
  scale: { i1: 1, i2: 1, i3: 1, soc: 1 },  // ← 需按实测标定（见 §6 C2）
  maxCurrent: 15
};
```
映射：`I1=i1*s1, I2=i2*s2, I3=i3*s3, SOC=cf.soc`，`I4 = I1 + I3 − I2`。

**B4. 逻辑差异（实时 vs 手动）**
- **市电切入判定**：实时模式下以 **I3 > 0** 为准（不再用 SOC 阈值判断）。
- SOC 环形表：直接用 BMS 的 SOC。
- 阈值刻度：仍保留手动滑块作参考；如需显示 BMS 侧"市电切换"设定值，可后续一并下发。

**B5. 交互**
- 切到"BMS 实时"：滑块变**只读**并跟随真实值回显；"自动演示"自动关闭。
- 提供"回到手动"释放滑块。

**B6. 视觉**
- 加 `BMS 实时 ●` 徽标 + 最后更新时间；离线时整体灰显并提示"未连接 BMS"。
- 量程自适应：真实电流若超出 0~15A，自动抬高 `MAXI`。

## 5. 联调步骤
1. 编译上位机 → 接 BMS → 打开串口 → **停在"电池信息"页**。
2. 浏览器开 `http://localhost:8712/`（或 `http://localhost:8712/api/bms` 看 JSON）。
3. 网页切"BMS 实时"，确认电流/SOC 随实测变化、流向正确。
4. 标定 `scale`（见 §6）。
5. 展会另机展示：把监听改 `0.0.0.0` 并放行防火墙，用 `http://<上位机IP>:8712/` 访问。

## 6. 待你拍板的点 / 风险
- **C1 单位**：`iSolar` / `Current` / `iMainSupply` 的实际单位是什么（0.1A？A？）？
